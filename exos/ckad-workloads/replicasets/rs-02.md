# rs-02 — Corriger un sélecteur hérité

Niveau 3 — 20 minutes

Contexte : namespace `ckad-rs-02`.

Préparez le scénario avec `./lab.sh start rs-02`.

Le ReplicaSet `api-rs` utilise encore les métadonnées d'une ancienne
application. Corrigez-le pour obtenir :

- sélecteur et label du template `app=api-v2`;
- 3 réplicas;
- conteneur `api` avec `nginx:1.27.3`;
- 3 réplicas disponibles.

Tenez compte du caractère immuable de certains champs Kubernetes.
