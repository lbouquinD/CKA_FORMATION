# rs-01 — Créer un ReplicaSet

Niveau 1 — 15 minutes

Contexte : namespace `ckad-rs-01`.

Créez un ReplicaSet `frontend-rs` :

- 3 réplicas;
- sélecteur `app=frontend`;
- template portant le même label;
- conteneur `nginx` avec l'image `nginx:1.27.3`;
- tous les réplicas doivent être disponibles.

N'utilisez pas de Deployment pour cet exercice.
