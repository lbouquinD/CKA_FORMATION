# ds-03 — Tolérer un nœud dédié

Niveau 3 — 20 minutes

Contexte : namespace `ckad-ds-03`.

Préparez le scénario avec `./lab.sh start ds-03`.

Une nouvelle politique de cluster réserve certains nœuds avec le taint
`dedicated=observability:NoSchedule`. Le DaemonSet `log-agent` doit anticiper
ce déploiement, sans que le laboratoire ne modifie les nœuds partagés.

Corrigez son template pour ajouter une tolérance exacte :

- `key: dedicated`;
- `operator: Equal`;
- `value: observability`;
- `effect: NoSchedule`.

Conservez l'image, la commande et le sélecteur existants. Tous les Pods désirés
doivent être disponibles.
