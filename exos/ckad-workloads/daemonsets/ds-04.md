# ds-04 — Mise à jour OnDelete

Niveau 3 — 20 minutes

Contexte : namespace `ckad-ds-04`.

Préparez le scénario avec `./lab.sh start ds-04`.

Modifiez le DaemonSet `manual-agent` :

- stratégie de mise à jour `OnDelete`;
- nouvelle image `busybox:1.36`;
- supprimez ensuite ses anciens Pods pour déclencher leur remplacement;
- attendez que tous les Pods désirés utilisent la nouvelle image;
- écrivez leurs noms triés dans `/tmp/ckad-ds-04.txt`.
