# ds-02 — Ciblage des nœuds Linux

Niveau 2 — 20 minutes

Contexte : namespace `ckad-ds-02`.

Créez un DaemonSet `linux-collector` avec le conteneur `collector` et l'image
`busybox:1.36`.

- le template doit cibler uniquement les nœuds portant
  `kubernetes.io/os=linux`;
- la commande doit maintenir le conteneur actif avec `sleep 3600`;
- le sélecteur et le template utilisent `app=linux-collector`;
- tous les Pods désirés doivent être disponibles.
