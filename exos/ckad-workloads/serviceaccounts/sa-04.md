# sa-04 — Changer l'identité d'un Deployment

Niveau 2 — 10 minutes

Contexte : namespace `ckad-sa-04`.

Préparez le scénario avec `./lab.sh start sa-04`. Le Deployment `reporter`
tourne avec le ServiceAccount `default`.

1. Créez le ServiceAccount `reporter-sa`.
2. Faites tourner `reporter` avec `reporter-sa`.
3. Gardez le nom, l'image, le label `app=reporter` et les 2 réplicas.
4. Les 2 Pods `Ready` utilisent `reporter-sa`.
