# sa-05 — Jeton projeté pour un tiers

Niveau 3 — 18 minutes

Contexte : namespace `ckad-sa-05`.

Préparez le scénario avec `./lab.sh start sa-05`. Le ServiceAccount
`api-client` existe déjà.

Un coffre-fort externe accepte les jetons Kubernetes dont l'audience vaut
`vault`. Créez le Pod `audience-app` :

- ServiceAccount `api-client` ;
- conteneur `app`, image `busybox:1.36`, qui reste actif (`sleep 3600`) ;
- volume `vault-token` qui projette un jeton du ServiceAccount :
  - audience `vault` ;
  - durée de vie `3600` secondes ;
  - fichier `token` ;
- volume monté en lecture seule sur `/var/run/secrets/vault` ;
- le Pod est `Ready`.

Le jeton est dans `/var/run/secrets/vault/token`.
