# sa-02 — Pas de jeton monté

Niveau 1 — 10 minutes

Contexte : namespace `ckad-sa-02`.

Cette application n'appelle jamais l'API Kubernetes. Elle ne doit pas recevoir
de jeton.

1. Créez le ServiceAccount `quiet-sa` qui désactive le montage automatique du
   jeton.
2. Créez le Pod `no-token` :
   - conteneur `app`, image `busybox:1.36`, qui reste actif (`sleep 3600`) ;
   - il utilise le ServiceAccount `quiet-sa`.
3. Le fichier `/var/run/secrets/kubernetes.io/serviceaccount/token` n'existe
   pas dans le conteneur.

Le réglage se fait sur le ServiceAccount, pas dans le Pod.
