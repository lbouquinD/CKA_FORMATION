# np-02 — Autoriser un client précis

Niveau 2 — 20 minutes

Contexte : namespace `ckad-np-02`.

Préparez le scénario avec `./lab.sh start np-02`.

Deux applications tournent : `web` (`app=web`) et `api` (`app=api`).

Créez une NetworkPolicy `api-allow` qui protège les Pods `app=api` :

- type `Ingress`;
- seul un Pod du même namespace portant `app=web` peut entrer;
- uniquement en TCP sur le port `80`.

`podSelector` désigne les Pods protégés. Les clients se déclarent sous
`ingress.from`, pas dans le sélecteur principal.
