# np-05 — Réparer la cible

Niveau 3 — 15 minutes

Contexte : namespace `ckad-np-05`.

Préparez le scénario avec `./lab.sh start np-05`.

La NetworkPolicy `allow-web` doit protéger les Pods `app=web` et laisser
entrer les Pods `app=client` en TCP sur le port `80`. Elle ne s'applique
pas aux bons Pods.

Corrigez uniquement la cible. Conservez :

- le nom `allow-web`;
- la source `app=client`;
- le port TCP `80`;
- le type `Ingress`.
