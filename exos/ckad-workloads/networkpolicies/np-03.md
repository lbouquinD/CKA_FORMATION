# np-03 — Autoriser un autre namespace

Niveau 2 — 20 minutes

Contexte : namespace `ckad-np-03`.

Préparez le scénario avec `./lab.sh start np-03`.

L'API (`app=api`) ne doit accepter du trafic que depuis le namespace
`ckad-np-03-clients`, déjà labellisé `role=clients`. Tous les Pods de ce
namespace sont concernés, pas un label de Pod en particulier.

Créez une NetworkPolicy `allow-clients` :

- protège `app=api`;
- type `Ingress`;
- `namespaceSelector` sur `role=clients`;
- TCP port `80`.

Dans un même élément `from`, `podSelector` et `namespaceSelector` se
combinent (ET). Ici, seul le namespace doit filtrer.
