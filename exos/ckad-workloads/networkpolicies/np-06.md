# np-06 — Entrée et sortie

Niveau 3 — 25 minutes

Contexte : namespace `ckad-np-06`.

Préparez le scénario avec `./lab.sh start np-06`.

Verrouillez les Pods `app=api` dans les deux sens.

Créez une NetworkPolicy `locked-api` :

- protège `app=api`;
- `policyTypes` contient `Ingress` et `Egress`;
- entrée : Pods `app=web` du namespace, TCP `80`;
- sortie : Pods `app=db` du namespace, TCP `5432`.

Les deux directions doivent être citées dans `policyTypes`, sinon la règle
correspondante n'a aucun effet.
