# np-04 — Limiter le trafic sortant

Niveau 2 — 20 minutes

Contexte : namespace `ckad-np-04`.

Préparez le scénario avec `./lab.sh start np-04`.

Les Pods `app=api` ne doivent ouvrir une connexion sortante que vers les
Pods `app=db` du même namespace, en TCP sur le port `5432`.

Créez une NetworkPolicy `api-egress` :

- protège `app=api`;
- `policyTypes` contient `Egress`;
- une règle `egress` vers `app=db`, port TCP `5432`.

Sans `Egress` dans `policyTypes`, le bloc `egress` est ignoré. Cette
politique ne traite pas le DNS : ne l'ajoutez pas.
