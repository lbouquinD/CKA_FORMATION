# np-01 — Refuser tout le trafic entrant

Niveau 1 — 15 minutes

Contexte : namespace `ckad-np-01`.

Préparez le scénario avec `./lab.sh start np-01`.

Un Pod `web` est déjà là. Isolez **tous** les Pods du namespace : plus aucun
flux entrant ne doit être autorisé.

Créez une NetworkPolicy `deny-ingress` :

- `podSelector` vide (`{}`), donc tous les Pods du namespace;
- `policyTypes` contenant `Ingress`;
- aucune règle `ingress`.

Une règle absente ou une liste vide signifie « rien n'est autorisé ». Un bloc
`ingress` avec une entrée vide autoriserait au contraire tout le monde.
